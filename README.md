# avoid-zombies-in-city
---
## 게임소개
평범한 좀비 게임이고요, 클로드로 만들었습니다. 순수 AI 딸깍으로 만든거니 그냥 즐겨주세요. 사실 재미없습니다.
## 사용법
별거 없어요. `W,S,A,D` 로 이동, `마우스` 로 시점 이동, `Space` 로 점프, `Esc` 로 정지, `Shift` 로 달리기입니다.
## 지원 기기
키보드와 마우스가 있는 대부분의 기기에서 지원됩니다. 터치 지원은 안됩니다.
